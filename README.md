# まんまるぶうの冒険 ― 封印の祠

Three.js製の第一章。10日前に魔物に連れ去られたまま帰らないリリィを助けるため、古塔・洞窟・遺跡で封印を解き、祠の主に挑む。救出後はリリィと村へ帰り、モーリとの再会で章クリア。

## 起動

Node.js 22.12以降で `npm install`、`npm run dev`。
ブラウザで http://127.0.0.1:5173/ を開く。Windowsでは「冒険をはじめる.cmd」でも起動できる。

タイトルの画質を選んで「冒険をはじめる」。高負荷なら「標準」「軽量」へ切り替える。解像度・影・草花・描画距離・テクスチャ・毛・AO・ブルーム・粒子・fps上限はメニューで個別調整できる。

画面左上の案内と、大きな金色の「！」・光の柱・行き先名が次の目的地を示す。画面外の目的地には縁の矢印が向く。右下には北が上のミニマップがあり、青い矢印で現在地と向きを示す。Mの大きな地図には実際の道・建物・入口・宝箱・休息地点・目的地とエリアの接続図が載る。地図の目的地も「！」で統一している。村と森の境界は、道の奥まで歩くと自動で切り替わる。家の扉はEで開閉し、そのまま歩いて出入りする。屋内では屋根と手前の壁が消える。

冒険メニューは「つよさ・どうぐ・そうび・スキル・旅のきろく・設定」の6項目。道具5種と装備36点には専用イラストがあり、効果・回復量・能力差を確認できる。装備画面は性能と見た目を別々に選べて、まんまるぶうの全身を回転して確認できる。スキル配分は確定前に戻せる。地図ボタンは置かず、Mキーで開く。クレジットは設定内にある。戦闘では敵の名前をクリックして対象を変える。コマンド・特技・道具にカーソルを合わせると、効果・対象・消費MP・使えない理由が表示される。キーボードのフォーカスでも説明が出る。

## 第一章の進み方

1. 村の広場のモーリに話しかける。10日前の失踪について聞き、救出の依頼を受ける。誘拐の実演はない。
2. 北門から森へ。西の古塔で左から「芽・太陽・月」に回転盤を合わせ、装置を調べる。
3. 東の洞窟で岩鎧のガルムを倒し、紋章を手に入れる。
4. 森の奥の祠前庭で、紋章を台座へ戻す。
5. 森の北西の遺跡で、西の水門、東の水門を操作。渡れるようになった橋を進み、祭壇を灯す。
6. 祠へ戻り、開いた石扉の先へ。回廊、祭室を降り、最深部のヴェルガを倒す。
7. リリィに話しかけて救出。地上への近道と「一緒に村へ帰る」、または帰りの鈴で凱旋する。

ボス到達の推奨レベルは25。回復の灯は無料。村の宿・道具屋・装備屋・礼拝堂も利用できる。

## 育成・戦闘

- 上限Lv30。Lv2以降は毎回4SP。たいじゅつ・まもり・ひだまり・かぜの四系統へ手動配分。各系統100SP、通常特技16と常時効果16。
- 村の礼拝堂で無料の振り直し。特技はレベルによる自動習得ではない。
- ツノドリルは独立した「ひっさつ」。MP0、SP不要。攻防で100までチャージし、成立後3回の行動選択機会まで使える。戦闘の外へ持ち越さない。
- 探索中の敵は視界と遮蔽物を判定し、発見→警戒→追跡。5レベル以上強い相手から通常敵は逃走し、行動圏を出ると縄張りへ戻る。
- 戦闘中は生きている標的や攻撃している敵へ向き続ける。コマンドカメラはまんまるぶうの斜め後ろ。攻撃は同じ側から滑らかに追い、命中時の逆向きカットを挟まない。カメラ前に木を置かない。
- 接近攻撃後はまんまるぶうも敵も元の陣形へ走って戻る。勝利後は確認式のリザルトでEXP・G・レベルと能力の上昇・獲得SP・戦利品・次の目的を表示。物語報酬も合算し、一度だけ受け取る。
- リザルトを閉じるまで勝利モーションを繰り返し、戦闘曲からリザルト用BGMへ切り替える。レベルアップ時は専用ジングルを1回再生する。
- 打撃の斬撃・衝撃波、風の渦、光の柱、炎と火の粉、影の紋、回復の光、防御ドームなどを使い分ける。ツノドリルは螺旋と多重の衝撃波、流星技は落下光と岩の破片を重ねる。粒子数は品質設定に連動する。
- 敗北はKOモーションと「負けてしまった……こもれび村に戻ります」を表示。「村へ戻る」で確認後、所持金10%を失って村で全回復する。
- 敵は最大三体。予告、回復、かばう、毒、眠り、幻惑、MP封じ、属性、段階変化、召喚を使う。
- 五部位・36点の装備。能力装備と外見装備を別に選べる。「装備を外す」「見た目を隠す」に対応し、非表示も保存する。目と耳を覆わない小物、帽子、ケープ、足輪などをボーンへ取り付ける。
- 救出後は洞窟、遺跡、祠に「残響の試練」。初回報酬は暁の装備。繰り返し挑戦できる。

## 素材と描画

Quaterniusの手元のStandard版三キットから97モデルを選抜。モジュール建築12棟、扉を開けてシームレスに歩ける室内6軒、森、三層の古塔、洞窟、遺跡、前庭、地下の祠を新規構成している。反復する建築・自然物を空間ごとにインスタンス化。

街は白壁・木骨と大きな瓦屋根を基本に、宿の隅塔、長老の塔屋、礼拝堂の鐘楼、屋根窓、バルコニー、店の布庇、鍛冶場、パン窯、水車を組み合わせる。屋根は用途ごとに青緑・煉瓦・青・紫などの色を設定。花壇、鉢植え、柵、街灯、窓と鎧戸が通りを囲む。

地形は見た目と歩行で同じ高さ関数を使い、村の高台・平らな家の基礎・森の丘陵・川岸を構成。村220×200m、森440×380mの余裕ある地形を、半径590mまで連続する丘陵へつなぐ。遠景の木も同じ地形高へ接地させる。森から村を見る方向に門・家並み・鐘楼、村の北門には森へ続く林道を配置する。地面は写真を使わない草地・土・石畳の専用描画。世界座標で模様の大きさを揃え、草地の色むら、風で揺れる立体の草、まとまった草花を重ねる。近景の草と約4.7万組の遠景草を別々にセルごとにインスタンス描画し、品質設定で表示密度と描画距離を調整する。青空と柔らかな日光、Fog、AOを組み合わせる。

ウサギNPCは廃止。KayKit Adventurers 2.0の5種の人型モデルと、Character Animations 1.1の65クリップを読み込み、歩行・挨拶・待機・作業・救出帰還へ使用。モーリは固有の服と白い髭で区別し、村に一人だけ配置する。

まんまるぶうは、許可された元の戦闘モーション入りBlenderモデルから派生書き出し。元の布材質の色と法線を、鼻・手先・足先を含む11部位へベイクしてピンクを復元。590本の実ループ毛を抽出し、刺繍の目は縮尺を考慮した糸の太さで再構成する。目の糸に毛用の光沢を適用せず、13モーションを保持する。

LODは102,978 / 38,274 / 16,716三角形。中・遠景の形状は高品質版と材質を共有。高品質の近景だけループ毛を追加表示する。眼の最終的な見え方、戦闘カメラの気持ちよさ、実機fpsはユーザーのレビュー対象。

音源はユーザー指定のaudio-libraryから40本をコピーし、レベルアップ用に魔王魂「ジングル07」を1本追加。元ファイルは変更せず、計測済みの長さ・音量に基づいて再生ゲインを調整。BGMはクロスフェード、足音は移動中のループ再生。曲や音質の再評価はしていない。

音楽・レベルアップ効果音：魔王魂／作曲：森田交一。その他効果音：効果音ラボ。
