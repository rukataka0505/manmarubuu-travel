# 冒険メニューの刷新 — 2026-09-27

旧「冒険の手帳」を置き換え、Tabで開く冒険メニューを新規実装した。
左で目的を選び、中央で対象を選び、右で詳しい内容と実行結果を確かめる構成。
紺青・青緑の面、落ち着いた金の枠、明朝の見出しを基調とし、大きな道具絵とまんまるぶうの全身表示を使う。

## 各画面

- **つよさ**：待機モーションを繰り返す3Dプレビュー、HP・MP、主要能力、次のレベルまでの経験値、現在の5部位の装備、4系統の習得ポイント、次の目的。
- **どうぐ**：道具5種をイラスト付きで表示。「すべて」「HP・MP」「旅の支度」で絞り込み、所持数・説明・実際の回復量を表示。HP・MP満タン時の無駄な消費を防ぐ。状態回復アイテムは戦闘で使用する。
- **そうび**：5部位の切り替えと所有品一覧。「性能を変える」「見た目を変える」を分離。変更前後の6能力と増減、固有効果、装備解除、外見の非表示、性能装備への見た目リセット。現在の装いは全身プレビューに反映される。
- **スキル**：4系統それぞれ8段階の成長を表示。必要SP・消費MP・効果・習得状態を確認し、1P/4P/次の習得段階まで配分。確定前だけ1Pずつ戻せる。確定・取り消しを明示し、習得済みのポイントは戻さない。全振り直しは既存の礼拝堂を使う。
- **旅のきろく**：10日前に連れ去られたリリィを救う目的、今やること、行き先、古塔から凱旋までの進行。
- **設定**：画面、戦闘・案内、音量、操作に分ける。既存の設定項目は維持し、クレジットはここから開く。
- **道具屋・装備屋**：同じイラストと詳細表示を使い、価格・所持数・装備の能力比較・購入後の所持金を示す。

地図ボタンはメニューとHUDから外す。**Mの大きな地図と右下のミニマップは維持**し、ミニマップは操作ボタンを持たない表示にする。

## 操作と表示負荷

- Tab / Esc：冒険メニューを閉じる。↑↓：選択。←→：操作する欄を移る。Enter / Space：決定。マウスでも操作可能。
- まんまるぶうはドラッグまたは回転ボタンで回す。探索中の向きとカメラは変えない。
- 3D表示は現在のモデルと装備を複製した独立した骨格で再生。元のジオメトリ・テクスチャを共有し、独立した小さな描画領域を30fps上限で描く。閉じている間は描かない。
- メニュー中の背景ワールドは静止画として保持。設定変更時など必要な場合のみ再描画する。
- メニューの最大幅は1340px。1440×900と1024×640の画面で、固定ヘッダー・フッターと個別のスクロール領域を使う。
- 元のキャラクターモデル、ストーリー・報酬・戦闘演出、既存セーブの構造を変更していない。
