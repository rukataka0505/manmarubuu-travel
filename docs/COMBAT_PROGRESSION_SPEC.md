# 封印の祠 ― 戦闘・育成・装備仕様

v1.1 / 2026-09-26。今回のユーザー指示を反映した実装基準。数値は初期バランス値であり、試遊済みの値ではない。

## 1. 基本方針

主人公の呼称は会話、UI、説明、通知、クレジットを含め「まんまるぶう」で統一する。通常の特技と独立した必殺技「ツノドリル」を分離する。

物語はリリィ救出から村での再会までを維持。最終ボスへLv.25前後で到達し、その後も上限なしで育成を継続できる。第一章の初見時間は2.5～4時間を制作目安とする。レベルの数字だけを増やしたり、同じ敵を何度も倒す作業を必須にしたりしない。

操作キャラクターはまんまるぶう一人。敵は一体から最大三体の少数グループ。ボスは原則単体だが、後半の一時的な召喚を含め最大三体を守る。敵の組み合わせと倒す順番を、特技・装備選択の意味につなげる。

DQ9の参考点は、レベルアップで得たポイントを系統へ配分する育成、独立した必殺コマンド、装備を外見へ反映する体験。職業・転職・複数仲間まで一括導入しない。以下の4～10SP/レベル、見える0～100のチャージ、無料振り直しはこの作品用の独自仕様であり、DQ9の正確な内部仕様の再現とは扱わない。参考資料：[Nintendo配布のDQ9取扱説明書](https://csassets.nintendo.com/noaext/image/private/t_KA_PDF/DS_Dragon_Quest_IX?_a=DATC1RAAZAA0)。

## 2. レベルと成長曲線

| 進行 | 想定レベル | 主な成長体験 |
| --- | --- | --- |
| 村～森の入口 | 1～5 | 初めてのSP配分、ひっさつ、装備交換 |
| 森の奥～古塔 | 6～9 | 二つ目の特技、属性と敵の構え |
| 洞窟～ガルム | 10～14 | 少数グループ、状態異常対策、装備の選択 |
| 紋章返還～遺跡 | 15～19 | 主軸の育成が明確になり、全体への対応が増える |
| 祠上層 | 20～22 | 回復役・護衛役を含む敵編成 |
| 祠下層～最深部 | 23～25 | ビルドと装備を使った総力戦 |
| 祠の主 | 25前後 | 弱点、予告、防御、ひっさつを組み合わせる |
| 救出後の任意の挑戦 | 26～30 | 系統の完成、別ビルド、最終装備 |

Lv.25は推奨到達値であり入場条件ではない。上手く組めば低いレベルで勝て、必要ならさらに育成できる。敵の強さはエリアで固定し、育てるたびに敵も同じだけ強くなる自動レベル追従はしない。

次のレベルまでの経験値は L を現在レベルとして 20 + 12L + 4L²。Lv.25到達の累計は23,680、Lv.30は40,020。レベルがまとめて上がる場合も一段ずつSPを付与する。

道中は40～55回程度の戦闘と探索・会話を制作目安にする。通常戦の経験値は地域に応じ約30～900、必須の節目の報酬も使い、主経路でLv.24～26になるよう配置単位で収支を組む。経験値不足を無制限の敵再出現で埋めない。節目報酬は同じイベントで二度受け取れない。

能力値はHP、MP、攻撃、守備、すばやさ、魔力（属性技・回復の補正）の六つ。レベルで基礎値が上がり、SPと装備で役割を分ける。基礎値の初期式はHP=50+10(L−1)、MP=16+3(L−1)、攻撃=12+3(L−1)、守備=6+2(L−1)、すばやさ=9+2(L−1)、魔力=10+3(L−1)。すばやさは行動順に加え、物理攻撃への回避にも寄与する。速度回避ボーナスは min(15%, 15%×log(1+すばやさ/20)/log(9)) とし、160以上では15%を上限とする。

レベルアップ時はHP・MPを全回復する。レベル上限は設けない。必要経験値や装備の金額はコード内へ散らさず、内容データで管理する。

## 3. スキルポイント

- Lv.1のSPは0。到達Lv.2～5は4SP、Lv.6～10は5SP、Lv.11～15は6SP、Lv.16～20は7SP、Lv.21～25は8SP、Lv.26～30は9SP、Lv.31以降は10SPを各レベルアップで付与する。累計はLv.10で41SP、Lv.20で106SP、Lv.30で191SP、Lv.31で201SP。
- 「たいじゅつ」「まもり」「ひだまり」「かぜ」の4系統へ1SP単位で配分する。各系統は最大100SP。
- 系統内の累計4/10/18/28/40/55/75/100SPで特技または常時効果を得る。下位の取得を前提とする一本の系統で、複雑な枝分かれUIは作らない。
- 未使用SPは保存できる。振り分け画面は確定前のプレビューとキャンセルを持ち、次の解放と必要ポイントを表示する。
- 通常特技はレベルだけでは自動習得しない。装備から通常特技を重複配布することもしない。
- 村の礼拝堂で、戦闘外なら全系統または一系統を無料で振り直せる。不要になった特技のお気に入り登録は解除する。
- 上限まで育てても全系統は完成しない。「100＋16」「75＋40＋1」「55＋55＋6」などの個性を残す。

## 4. ひっさつチャージとツノドリル

通常特技一覧からツノドリルを外し、「ひっさつ」コマンドへ移す。習得SP不要、MP消費0。依頼後の最初の戦闘で仕組みを紹介し、初回だけチャージ成立を一度保証する。以後は通常ルールで溜める。

| 項目 | 仕様 |
| --- | --- |
| チャージ | 0～100。戦闘開始時0、戦闘終了・逃走・全滅で解除。探索や宿で溜めない |
| 基本加算 | 自分の有効な行動完了で+8。待機・失敗した入力・メニュー開閉は加算なし |
| 被ダメージ | 敵の一行動の総被害Dに対して min(25, 8＋floor(30×D/最大HP))。D=0なら加算0 |
| 防御の見せ場 | 予告された大技を防御系コマンドで受け切ると+15。敵行動群あたり一回 |
| 加算の上限 | 敵行動群からの全加算は合計30まで。多段攻撃や召喚数で無制限に増えない |
| 使用可能状態 | 100で「ひっさつチャージ！」。次から自分が行動を選べる三回の機会まで保持 |
| 猶予の減少 | ひっさつ以外のコマンドを確定して実行した時に一回減る。キャンセルや操作不能中は減らない |
| 消費と再充填 | 発動開始時に100消費。ツノドリル自体からは加算なし。その後の敵行動から再充填できる |
| MP封じ | MPが0、またはMP封じ中でも使える。眠りで行動不能中は選択できない |
| 威力 | 単体へ通常物理の4.0倍、対象守備の40%を無視、必中。光・風等の特定ビルドを要求しない |
| 相手の構え | 通常敵の構えを解除できる。ボスの段階やイベントを強制スキップしない |
| 演出 | 顔と角の寄り→溜め→高速の螺旋突進→命中→着地。通常版4.5～5.5秒、速い設定は短縮 |

防御系への寄り道や装備の工夫がチャージに役立つが、わざと長時間被弾し続けることを必須戦術にしない。ボス戦では通常の攻防で複数回使える想定。物語の扉やボスの撃破条件に「必殺でとどめ」を要求しない。

チャージを成立させた行動そのものでは三回の猶予を減らさない。満タン時の追加チャージは溢れるだけで猶予を更新せず、使用または期限切れで0へ戻す。ひっさつゲージ、残りの使用機会、発動可能な理由を表示する。コマンドは「たたかう／とくぎ／ぼうぎょ／どうぐ／ひっさつ／にげる」の六つ。数字1～6に対応し、使用不能でもひっさつ欄は残して条件を示す。

## 5. 状態変化と複数敵の処理

物理、火、風、光、影の属性を扱う。敵の弱点は説明、見た目、発見済み情報で分かるようにする。弱点1.25～1.5倍、耐性0.5～0.75倍を初期値とし、必須ボスへ一つの系統だけを強制しない。

状態は毒、幻惑、眠り、MP封じ、攻撃上昇/低下、守備上昇/低下、速度上昇/低下、構え、ため、隙を用意する。同種は強い方と持続更新で扱い、無制限に重ねない。

毒は自分の行動終了時に最大HPの5%・三回で終了し、毒だけではHP1未満にしない。幻惑は五ターン継続し、攻撃属性に関わらず攻撃を50%でミスさせる。必中のツノドリルはこの判定を受けない。眠りは最大一回の行動休みで、解除後二回の行動機会は眠りへの耐性を付ける。MP封じは最大二行動分。状態は戦闘終了時に解除する。

一人用のため、敵が眠りを連打して永久に操作を奪う編成は作らない。状態異常解除、HP回復、MP回復の道具を店で常時買え、回復魔法なしの育成でも対処できる。自分へ付けた持続効果は付与した行動そのものを数えず、以後の自分の行動機会終了時に残り回数を減らす。眠りは休んだ機会も一回として数える。

ターン開始時に行動順を一度確定する。速度変化は次ターンから反映。防御・道具の先行は既定の優先度で処理する。「次の敵行動群」はそのターンの残りの敵全員の行動を指し、防御が最初の一発で剥がれないようにする。複数の軽減は最も強いものを基準にし、常時軽減込みでも通常の被害軽減上限は75%。幻惑と回避は単純加算せず、最終ミス率=1−(1−幻惑率)×(1−回避率)で独立合成する。通常の回避率と速度回避ボーナスは物理攻撃だけに適用し、幻惑は属性攻撃にも適用する。

全体技は全対象へ命中イベントを計画し、多段技は各段の対象を計画する。途中で対象が倒れたら次の生存対象へ移し、敵が全滅したら余った段を終了する。勝利は敵全滅時だけ判定する。召喚された敵は次ターンから動き、経験値・金は初期編成の報酬のみとする。

## 6. 敵の種類と行動

通常敵12種、強敵4種、物語ボス2体を第一章の制作目標とする。色違いだけで数を稼がず、輪郭、部品、動作、役割のうち複数を変える。共有できるリグと素材は共有する。

強敵は古塔の「風冠のモス」、洞窟の「黒甲のコロガシ」、遺跡の「火守りの石兵」、祠の「影の近衛」。通常種から専用部品と一つ以上の固有行動を加え、任意の脇道へ置く。装備の選択肢や経験値を報酬にするが、救出の必須条件にはしない。

AIは条件付きの優先度と重みで行動を選ぶ。HP、仲間の残HP、前の行動、構え、クールダウンを見る。回復は対象HP50%未満、三ターン間隔。強い技は先に予告し、同じ強技の連打を禁止する。単に全ての技をランダム抽選しない。

複数敵は「攻撃役＋回復役」「硬い敵＋速い敵」など役割を組み合わせる。同じターンに全員が行動不能技を使う組み合わせは避ける。敵の予告はそれぞれの名前とアイコンに紐づけ、三体の大技を一斉に浴びる理不尽さを避ける。

### 中ボス：岩鎧のガルム（Lv.12～14目安）

岩殻防御→拳打／投石→叩きつけ予告→大技後の隙。HP50%以下で殻が割れ、防御が下がる代わりに二連撃を使う。物理・属性どちらの育成にも攻め時がある。通常戦の敵より長い3～5分程度を目安にする。

### 祠の主ヴェルガ（Lv.25目安）

前半は爪、影弾、MP封じ、薙ぎ払いの予告。HP50%以下で一度だけ段階移行し、影の眷属を最大二体召喚する。眷属の再召喚はしない。後半は予告付きの突進と衝撃波を使い、一ターンに最大二行動。大技と行動不能を同じターンに重ねない。

二行動と召喚を含めた総被害でバランスを取る。推奨装備と防御を使えば満タンから一ターンで倒されない初期調整とする。回復系統を必須にせず、道具持ち込みでも勝てることをロジックで確認する。目標時間は5～8分。ひっさつは攻め時を作るが、倒すための抽選待ちにしない。

計36点を作る。推奨Lv.1/7/13/19/25/30の段階に分け、同じ時期にも攻撃寄り、防御寄り、属性寄りの選択を置く。推奨レベルは装備制限ではない。装備品に重量や耐久減少は設けない。

例：いばらのツノ輪は攻撃、風読みのツノ輪は速度と風、守り樹の胴当ては物理防御、灯守りのケープは影耐性、花の髪飾りは魔力、目覚めのおまもりは眠り耐性。必殺を支える「勇気のおまもり」は敵行動群からのチャージ+3、上限30は変えない。純粋な上位互換だけにしない。

入手は店、固定の宝箱、任意の強敵、物語報酬。主要な装備を低確率ドロップに限定しない。店は救出の進行で品揃えが増え、通常の戦闘収入で各節目に主力一～二部位を更新できる価格にする。クラフトやランダム付与の大量厳選は第一章の必須要素にしない。

全ての部位を外見へ反映する。36点ごとに完全に別のリグを作らず、部位ごとの複数の形状を共有し、材質・装飾部品で変化を付ける。系列が変わる主要装備では輪郭も変える。頭はHead、ツノ飾りはHead上の専用取付点、胴はBody、足は左右Footへ追従。布は簡単なボーンまたは揺れで表現する。

まんまるぶうの毛、刺繍の目、ピンクの鼻、丸い輪郭を覆い隠さない。装備画面で全身を回転でき、変更前後の能力差・耐性・外見を比較できる。所持している装備を使った部位別「見た目だけ変更」も用意する。性能装備と見た目装備は別IDで保存し、未所持品は指定できない。

装備変更と振り直しは戦闘外だけ。最大HP/MPが変わっても現在値は増やさず、新しい最大値まで切り詰める。着脱による無限回復や常時効果の二重加算を防ぐ。

## 8. Lv.26～30の範囲

救出後は、既存の洞窟・遺跡・祠を使った三つの任意の「残響の試練」を解放する。初回クリア報酬に最終装備を置く。リリィが再誘拐されたり、討伐済みの主が物語上復活したりしない、封印の記憶との模擬戦として扱う。

Lv.30までに想定した基礎値、全32解放点、最終装備、敵編成を実装範囲に含め、SPは5レベルごとに4→5→6→7→8→9→10と増え、Lv.31以降は10SP/レベルで継続できるようにする。まず章の通しプレイを成立させて見せ、その後の完成版ではこの範囲も揃える。第二章や新たな広大なマップは追加しない。

## 9. 実装契約と確認範囲

内容データはlevelCurve、skillTrees、skillDefinitions、equipment、appearance、enemyDefinitions、encounterGroups、bossPhases、chargeRulesに分ける。RPGの計算はモデル・音・カメラから独立させる。

保存するのはLv/XP、系統別配分、未使用SP、所持装備、性能装備、見た目装備、特技のお気に入り、試練初回報酬。習得特技と最終能力値は配分・装備から再計算し、別の正本を増やさない。未使用SP＋配分SP＝4×(Lv−1)を必ず満たす。ひっさつチャージと状態変化は戦闘限定で、探索セーブへ引き継がない。

一体用のenemyをenemies配列へ変更し、stableなbattleActorIdで対象を指定する。行動の消費は開始時に一回、ダメージは命中時に一回。敵全滅判定、途中撃破、多段対象変更、全体攻撃、反撃、召喚、ボス段階移行も同じイベント列で処理する。反撃から反撃を発生させない。

機械で確認するのはSPの付与・振り直し・セーブ、能力値と装備の再計算、チャージの回数・消費・期限、状態異常の解除、AIの禁止条件、複数敵の勝敗、経験値の収支、進行の詰まりである。有限のheadlessスモークでは実際のコマンドとイベントを通す。

見た目、カメラの気持ちよさ、装備の似合い方、ゲーム実画面での確認、最終の難易度評価は相棒に任せる。スクリーンショットや録画によるAIレビューはしない。音の品質評価・曲選びのやり直しも行わず、長さと音量の計測だけを担当する。
