# 2026-09-27 試遊フィードバックの実装

この改修は第一章の救出・帰還フローと保存領域を引き継ぎ、街・探索・操作・戦闘の構造を変更する。旧ウサギNPCと別エリアの家は廃止。旧Unity版のコード・シーン・設定は参照していない。

## マップと探索

- `terrain.js` の同じ高さ関数から地形メッシュと歩行位置を計算。村は礼拝堂の丘、家ごとの平らな基礎、川岸、畑と庭。森は起伏のある主路と丘陵。
- 三層の山並み、遠景の樹林、外周へ連続する地面を追加。カメラの標準角度を下げ、前方の建物と景色を見渡せるよう変更。
- 最新のアート方針に合わせ、写真の地面素材を廃止。草地・土・丸い石畳をCanvasで描き、世界座標で実寸のタイル密度を揃える。草地は大きな色むらと、風で揺れる立体の草を重ねる。道の面を上向きに修正して表示を復旧。影、植生密度、距離による表示、テクスチャの品質設定を維持。
- 白い塗り壁と木骨を街の基調にする。宿の円塔、長老宅の塔屋、礼拝堂の鐘楼、屋根窓、バルコニー、商店の布庇、鍛冶場の屋根、パン窯の煙突、水車で建物ごとのシルエットを変える。屋根の色を用途別に設定し、開口部には実際の窓と鎧戸を配置。
- 建物脇の花壇、広場の植栽、鉢と街灯、川岸の岩、森の岩場・シダ・きのこを集団で配置。環境モデルは97種。立体の草は村で約2.1万組、セルごとにインスタンス化し、品質設定で密度を落とす。背景には距離による色の薄れを持たせる。
- Spaceで跳躍。既存のJump_Start / Jump_Air / Landingを使用。水平移動は壁の衝突を通し、接地は地形の高さへ戻す。
- 建物6軒は村の同一座標に室内を配置。Eで蝶番を回し、扉が開いてから衝突を解除。そのまま歩いて入れる。入室時に屋根・上階・手前の壁を非表示にする。
- 家は用途別の家具と室内灯を持つ。NPCは村の一つのリストから生成し、室内用に同じ人物を複製しない。旧セーブの `interior` は対応する村の家へ移す。

## NPCと敵

- KayKit Adventurers 2.0 FREE のMage / Ranger / Rogue / Knight / Barbarianを採用。
- KayKit Character Animations 1.1のGeneral / MovementBasic / Simulation / Toolsから65クリップを読み込む。各人は複製したスケルトンとAnimationMixerを持つ。
- 住人の待機、歩行、近づいた際の挨拶、鍛冶や作業を接続。リリィの救出・同行・再会も同じ人型モデルへ変更。
- モーリは深緑の服と白い髭。一般の住人にMageを使い回さず、同じ長老に見える人物を避ける。村のモーリIDは常に一つ。
- 敵AIは徘徊→発見→警戒→追跡、または逃走。視野・壁の遮蔽・距離を判定し、5レベル以上強い主人公から通常敵が逃げる。強敵は逃げない。行動圏を越えると帰還し、短い再警戒待ちを置く。
- 移動は歩行可能地点への複数方向のステアリングで障害物を避ける。「！」と「…」で反応を示す。手帳・会話・戦闘中は敵の移動を止める。

## 戦闘と装備

- コマンド選択中は選択した生存敵へ向く。敵の攻撃中は攻撃している敵へ向き、移動・命中後も毎フレーム更新する。敵も主人公へ向く。
- 戦闘舞台の樹木・柱をカメラ経路の外周へ移し、手前の葉で視界が隠れる配置を廃止。床は探索と同じ実寸の質感素材。森林戦には遠景と草花も配置。
- 各装備部位に「性能に装備」「装備を外す」「見た目にする」「見た目を隠す」。見た目のみの変更は能力値へ影響しない。非表示も保存し、装備を外すと既定の見た目も解除する。
- 装備画面に回転ボタンを追加。足装備はglTFで正規化されたボーン名にも対応し、足の動きへ追従させる。
- 鼻・手先・足先が白くなる原因だった、glTFへ渡らないBlenderの手続き材質を修正。元材質の色と法線を11部位にベイクし、軽量LODも同じUVで書き直した。鼻・手先・足先は元のDusty rose cotton。結び糸と鼻の刺繍にも元色を保持。
- 刺繍の目を毛のシーン光沢から除外。頭飾りとツノ輪の取り付け位置を表面へ出し、胴装備のケープを体の外側へ拡張。顔のピンク、目、耳を残して装備の違いを見せる。

## 案内と仕掛け

- 目的地の名前・方向・距離をHUDへ表示。世界の金色の◆も進行中の目的へ絞る。森では道路の分岐を経由した方向を案内する。
- 回転盤は専用の操作画面。「左の芽・中央の太陽・右の月」の対応、現在値、回転順、正解した盤を一画面で確認できる。揃うと起動ボタンが有効になる。
- 遺跡の案内は西の水門→東の水門→祭壇と切り替わる。封印返還、地下階層、ボス後のリリィ、帰還口も物語から導出する。

## 素材と検証

NPCモデル・アニメーションは合計約5.8MB。出典、ハッシュ、CC0ライセンスは `public/npcs`。写真の地面素材と取得スクリプトは削除し、専用の描画に置き換えた。元のBlenderモデルと音源は変更しない。

`npm run check` は15項目のロジックテストと製品ビルド。`npm run test:smoke` は別保存領域で、誘拐・回転盤・9エリアの進行地点への到達・6軒の実移動での出入り・ジャンプ・装備・品質変更・セーブ・Lv25条件のボス戦・救出・同行・再会・クリア後再ロードを検証する。元のユーザーセーブは操作しない。

必要な実画面確認は指摘された戦闘の遮蔽と村、室内、装備に限定。細かなスクリーンショット反復は行わない。実機性能と最終的な遊び心地は相棒の試遊で確認する。
