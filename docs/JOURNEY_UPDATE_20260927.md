# 導入・地図・戦闘リザルトの更新

2026-09-27。ユーザーの追加フィードバックを反映。冒険の主目的は最後までリリィの救出と村への帰還。

## 物語

リリィはまんまるぶうが村に到着する10日前に魔物に連れ去られ、まだ帰っていない。広場でモーリから過去の出来事と三つの封印の解除方法を聞く。誘拐の実演と魔物の追跡シーンは削除し、村人の初期会話も帰還を待つ内容へ変更した。リリィは帰還イベント完了まで村に出現しない。

保存キーは変更しない。旧 `abductionSeen` は読み込み時に `abductionKnown` に移行する。古塔以降の進行、装備、育成は引き継ぐ。

## 地図と入口の景観

- Mで大きなエリア地図を開閉。Escでも閉じる。Tabは手帳のまま。
- 右下ミニマップは北が上。青い矢印が現在地とまんまるぶうの向き、金色の◆が目的地。目的地が範囲外なら円周に方向を示す。
- 大きな地図は実際の地形高、道、建物、川、部屋、入口、宝箱、休息地点を描く。横欄には現在の目的、主な場所、エリアの接続図を表示する。
- 地形の地図画像はエリア生成時にキャッシュし、位置と向きだけ約12Hzで更新する。探索以外ではミニマップを隠す。
- 森の南側に村の門塔2本、白壁と木骨の家6軒、鐘楼を配置。村の北門には14本の木々で囲む林道と花の木製アーチを置く。入口の相互方向を景観で示す。遠方の村には重複NPCや重複依頼を作らない。

## 戦闘リザルト

勝利ポーズの後、プレイヤーが「冒険を続ける」またはEnter/E/Spaceで閉じるまで結果を表示する。

- 倒した敵とターン数
- 獲得EXP、ゴールド、現在の所持金
- レベルの変化、次のレベルまでのEXPとバー
- レベルアップ時の最大HP・MP・攻撃・守備・すばやさ・魔力の前後値と増加分
- 獲得SPと未使用SP
- 装備、消耗品、封印の紋章などの戦利品
- 次の目的

通常戦闘・ボス・試練の報酬と物語達成EXPを一箇所で確定してから表示する。リザルト中にも探索位置で記録し、画面を閉じる際に再支給しない。試練の装備とボスの物語報酬は初回のみ。

## 先行フィードバックの修正

- Blender材質の複製名末尾 `.006` を「06番の目の糸」と誤認しないように修正。左耳・右手の先は元の布とピンクのベイクをそのまま使う。
- 宝箱はスキンと骨を個別に複製して接地し、開閉クリップを再生する。位置と戦闘背景はユーザーが目視確認済み。
- 村220×200m、森440×380mへ拡張。背景は半径590mまで同じ高さ関数で連続する丘陵と樹林にし、木の根を地形に合わせた。近景草と遠景草を分け、品質設定でも遠方の被覆を残す。
- 戦闘後退を独立した帰還モーションにし、接近攻撃後は走って元の陣形へ戻る。敵も同じ位置へ戻り、次のコマンドでは標的に向き直る。
- HP0でKOを再生し、倒れた姿と「負けてしまった……こもれび村に戻ります」を表示する。プレイヤーの確認後に村へ移動・全回復・所持金10%減を一度だけ実施する。

## 確認方法

`npm run check`：22項目のロジックテストと製品ビルド。

`node tools/smoke-feedback.mjs`：材質、宝箱の骨と位置、遠景の接地、帰還モーション、KOと確認式帰村、各戦闘背景の描画エラーを確認。

`node tools/smoke-journey.mjs`：導入、M/Tab/Esc、現在地と向き、村と森の入口構成、リザルトの成長・戦利品・確定済み記録・一度だけの支給、1024×640での地図表示領域を確認。

`npm run test:smoke`：9エリアの到達可能性、6軒への実移動、ジャンプ、装備・外見、品質切替、保存と再開、Lv25条件のボス戦、封印解除、リリィ救出・同行・再会・第一章クリアまで実操作で確認する。

全て独立したブラウザ保存領域で実行する。新設の地図とリザルトのみ各1枚の画面確認を行い、スクリーンショット反復は行わない。体感、画質設定ごとの実機負荷、難易度の最終判断はユーザーの試遊に委ねる。
