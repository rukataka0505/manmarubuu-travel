# 戦闘演出・目的地表示・エリア移動の更新

2026-09-27。リリィ救出の章構成、育成・装備、確認済みの宝箱と戦闘背景を維持し、操作と演出への追加フィードバックを反映する。

## 戦闘の見せ方

- コマンド入力時はまんまるぶうの斜め後方から敵を見る。複数の敵では生存中の敵の中心を基準にする。
- 行動中は同じ側から接近と命中を追う。命中や時間の区切りで正反対のショットへ切り替えない。画角、注視点、位置は連続的に補間し、ヒットストップ中も視点を維持する。
- 近接攻撃後は走って元の陣形へ戻る。その間にコマンド用の視点へ滑らかに戻す。カメラ控えめ設定は入力時の構図を維持する。
- コマンド、特技、道具をホバーまたはフォーカスすると説明を表示。効果、対象、実際の消費MP、所持数、使えない理由を戦闘ルールから読む。ツノドリルはMP0とチャージ条件を明記する。
- 勝利モーションはリザルトを閉じるまでループ。回復などで同じクリップを一度だけ再生した後でも、ループ設定を再適用する。
- リザルトは戦闘曲から専用の再生枠へクロスフェード。既存の `event26` を使用し、閉じると現在のフィールド曲へ戻る。報酬にレベルアップが含まれる場合は専用SEを1回鳴らす。戦闘外の物語EXPによるレベルアップにも対応する。

## エフェクト

発動時の紋、移動中の軌跡、命中時の衝撃、残光を組み合わせる。

| 系統 | 表現 |
| --- | --- |
| 通常打撃・連撃・岩技 | 弧状の斬撃、火花、地面の衝撃波、破片 |
| ツノドリル | 螺旋の軌跡、多重衝撃波、金色の破片、大きな命中光 |
| 流星技 | 落下光、広がる波、跳ね上がる岩の破片 |
| 風 | 複数の螺旋、風の刃、舞い上がる光粒 |
| 光・炎・影 | 光柱と紋／火球と火の粉／紫の渦と暗い紋 |
| 防御・回復・強化 | ドームと円環／緑の光柱と星／足元の紋と上昇する光 |
| 状態異常 | 眠り・毒・砂煙の色と渦 |

パーティクルはGPU上で移動し、破片はインスタンス描画。品質の粒子設定で数を減らせる。演出終了後は使い捨ての形状・材質・数字テクスチャを解放する。

## 探索

- 村の北門と森の南口は、道の奥の境界を越えると自動で移動。Eは不要。依頼前の村の出口は案内を出し、境界手前へ戻す。
- 短い暗転中に移動先、出現位置、探索カメラをまとめて設定する。カメラの旋回角は保持し、前からのズームと後方視点の切り替えを混在させない。移動直後には再発火を防ぐ猶予を設ける。
- 目的地を大きな金色の「！」、光柱、足元の円環で示す。画面上には名前と距離、画面外なら方向も表示。Mの地図と右下ミニマップにも同じ目的地マークを載せる。
- 遠景用の草に入っていた近距離フェードを削除。近づいてもその草を残し、品質設定に応じた遠方のフェードだけを使用する。

## 検証

- `npm run check`：カメラの連続性、エリア境界、ヘルプの消費・使用条件を含むロジックテストと製品ビルド。
- `node tools/smoke-presentation.mjs`：歩行だけの村・森往復、カメラ向きの維持、実際のホバー説明、命中と帰還中のカメラ連続性、各エフェクトのシェーダー描画、勝利ループ、BGM・レベルSE、探索への復帰。独立した保存領域を使用する。
- `npm run test:smoke`：第一章の移動・装備・育成・封印・ボス・救出・帰還までの機能確認。

スクリーンショットを反復する調整は行わない。演出の迫力、操作感、実機での負荷はユーザーの試遊で判断する。

実行結果：ロジック27項目と製品ビルド、演出の機能確認10項目、第一章の通し確認18項目が成功。ブラウザ例外・シェーダーエラーは0件。KO後の確認画面と帰村も別途1回確認し、敗北確認まで移動せず、確認後に村・全回復・所持金10%減へ正しく復帰した。
